# Python Automation Toolkit

A beginner-friendly Python project demonstrating automation, file handling, modular programming, and basic data analysis.

## Features

### 1. File Organizer

Automatically organizes files into folders based on their file extensions.

Example:

```text
Documents/
├── pdf/
├── txt/
├── docx/
```

### 2. Student Report Generator

Generates reports containing:

* Total Marks
* Average Marks
* Maximum Marks
* Minimum Marks

Reports are stored in:

```text
student_report.txt
```

### 3. Task Manager

Manage daily tasks using file storage.

Functions:

* Add Task
* View Tasks
* Save Tasks Permanently

Data is stored in:

```text
tasks.txt
```

 4. Data Analyzer

Performs basic statistical analysis:

* Sum
* Average
* Maximum Value
